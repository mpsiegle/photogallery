# 📸 Photo Gallery — Michael Siegle

Live Site: [Photo Gallery](https://mpsiegle.github.io/photogallery/)

---

## 🚀 Project Overview  
This is a curated photo gallery project by Michael Siegle — a clean and minimalistic website showcasing photography work, visual compositions, or creative archives. It’s built to display images with an intuitive layout and responsive design.

---

## 🧱 Structure & Pages  
- `index.html` — Main gallery page, showcasing the images in grid or slideshow format  
- `css/style.css` — Styling for layout, grid, hover effects, responsiveness  
- `js/main.js` — (Optional) JavaScript for lightbox, interactive elements, filtering or sorting  
- `images/` — Directory containing all photo assets used
